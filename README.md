# 로또 발매기 프로그램 
- 로또 구매


- 로또 당첨 번호 + 보너스 번호 입력


- 로또 당첨 결과 및 수익률 출력 
___
## 기능 구현 목록
#### 1) 로또 구매 로직
- 사용자에게 로또 구입 금액 입력 받기 (단위: 1,000원) 


- 구입 금액에 해당하는 만큼 발행한 로또 수량 출력하기 



- 발행한 로또 번호 오름차순으로 정렬하여 출력하기 

&nbsp;

#### 2) 로또 당첨번호 만들기 로직 
- 사용자에게 당첨 번호(6개)를 입력 받기 (쉼표를 기준으로 구분하기)


- 사용자에게 보너스 번호(1개)를 입력 받기


- 당첨 번호(6개) + 보너스 번호(1개)로 이루어진 당첨번호 만들기 

&nbsp;

#### 3) 당첨 번호 확인 로직 
- Enum 클래스로 로또 당첨에 관련된 상수를 관리하기


- 사용자가 뽑은 로또 번호와 당첨 번호가 몇 개 일치하는 지 확인하기


- Enum 클래스를 이용해서 당첨 통계판으로 당첨 번호 개수를 관리하기

&nbsp;

#### 4) 당첨 통계 출력 로직
- 번호 일치 개수, 상금, 당첨 번호 개수를 형식에 맞게 출력하기


- 2등은 보너스 번호가 있는 지 확인하고 보너스볼 정보도 같이 출력하기 


- 수익률(수익 금액 / 투자 원금) x 100) 계산 후 출력하기 

&nbsp;

## 예외처리 구현 목록
#### 1) 로또 구입 금액 예외상황
- 숫자가 아닌 값을 입력한 경우 


- 1,000원으로 나누어 떨어지지 않는 값을 입력한 경우 


- 0 이하의 값을 입력한 경우 


#### 2) 당첨 번호 예외상황
- 숫자 형식이 아닌 값이 포함된 경우


- 6개가 아닌 경우 


- 1~45 범위를 벗어난 숫자가 포함된 경우


- 중복된 숫자가 포함된 경우 


#### 3) 보너스 번호 예외상황
- 숫자 형식이 아닌 값을 입력한 경우


- 1~45 범위를 벗어난 숫자를 입력한 경우 


- 당첨 번호와 중복되는 경우 

___
### 1. 기능 요구사항
#### 로또 요구사항
- 로또 번호의 숫자 범위는 정수로 1~45 까지이다. 


- 1개의 로또를 발행 시에는 중복되지 않는 6개의 숫자를 뽑는다. 


- 당첨 번호 추첨 시 중복되지 않는 숫자 6개 + 보너스 번호 1개를 뽑는다.


- 로또 구입 금액을 입력하면 구입 금액만큼 로또를 발행한다. 


- 로또 1장의 가격은 1,000원이다. 


- 제공된 Lotto 클래스를 사용해 구현해야 한다. 


#### 당첨 요구사항
- 당첨은 1등부터 5등까지 존재한다. 


- 당첨 기준과 금액은 아래와 같다. 
> 1등: 6개 번호 일치 / 2,000,000,000원
> 
> 2등: 5개 번호 + 보너스 번호 일치 / 30,000,000원
> 
> 3등: 5개 번호 일치 / 1,500,000원
> 
> 4등: 4개 번호 일치 / 50,000원
> 
> 5등: 3개 번호 일치 / 5,000원
 
- 로또 당첨 번호와 사용자가 구매한 로또 번호를 비교하여 당첨 내역 및 수익률을 출력하고 로또 게임을 종료한다. 


___
### 2. 입출력 요구사항

- 사용자에게 로또 구입 금액 입력 받기 (단위: 1,000원)


- 구입 금액에 해당하는 만큼 발행한 로또 수량 및 번호를 출력하기


- 로또 번호는 오름차순으로 정렬하여 출력하기


- 사용자에게 당첨 번호(6개)를 입력 받기 (쉼표를 기준으로 구분하기)


- 사용자에게 보너스 번호(1개)를 입력 받기  


- 당첨 내역(통계) 출력하기 


- 수익률 계산하여 출력하기 (수익률은 소수점 둘째 자리에서 반올림)

---
### 3. 예외처리 
-  사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생시킨다.

> 예외 상황 시 에러 문구 출력해야 한다.
> 
>에러 문구는 "[ERROR]"로 시작해야 한다."
> 
>에러 메시지를 출력한 후 그 부분부터 입력을 다시 받는다.
___
### 4. 프로그래밍 요구사항
- JDK 21 버전에 실행 가능해야 한다. 


- 프로그램의 시작점은 Application의 main()이다. 


- indent depth가 3을 넘지 않도록 구현한다. (2까지만 허용)


- 3항 연산자를 사용하지 않는다. 


- 함수가 한 가지 일만 잘 하도록 최대한 작게 (길이가 15라인 이하) 구현한다. 


- JUnit5와 AssertJ를 이용하여 구현한 기능에 대한 단위 테스트를 진행한다.


- else 예약어를 사용하지 않는다. (switch/case도 불허)


- Java Enum을 적용해 프로그래밍을 구현한다. 


- camp.nextstep.edu.missionutils에서 제공하는 Randoms 및 Console API를 사용하여 구현한다.
